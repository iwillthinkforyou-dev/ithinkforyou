Cancellation Policy

Last updated: 8 October 2026

1. About Cancellation

I THINK FOR YOU provides a human Third Person Perspective based on information submitted by a person. There is no mandatory fixed fee for receiving the service.

2. Cancelling a Request

If you have submitted a request and want to cancel it before the perspective has been prepared, contact us as soon as possible at hello@ithinkforyou.com and include any reference or ITFY ID available to you.

We will make reasonable efforts to stop processing a request that has not yet been completed.

3. If a Perspective Has Already Been Prepared

If the perspective has already been prepared or delivered, cancellation may no longer be possible. If a payment was made in connection with the request, any refund request will be considered under our Refund Policy.

4. Voluntary Contributions

A voluntary contribution is not a mandatory purchase price for the service. However, once a payment has been successfully processed, any request to reverse it will be handled according to the Refund Policy and the payment provider's applicable rules.

5. How to Contact Us

For cancellation requests, email hello@ithinkforyou.com. Please include your ITFY ID or transaction reference where available so that we can locate the relevant request.

6. Policy Updates

This Cancellation Policy may be updated from time to time. The latest version published on this page will apply from its stated update date.
